## Objective

Implement the Antigravity (`agy`) backend integration for Substrate pinned to CLI version 1.4.0: a normalizer translating agy NDJSON stream-json events (`init`, `step_update`, `result`) and stderr stream into canonical `BackendEvent` streams and `SessionResult` records; robust soft-deny detection scanning both `denied_actions` and stderr output (since agy exits 0 on auto-denied tools); computed usage cost calculation derived from token counts and `PricingTable` (since agy reports tokens only without cost); a full `HarnessAdapter` managing supervised process lifecycle, arguments, environment scrubbing, and raw stream persistence; a fake agy dialect emulator supporting all conformance scenarios; and comprehensive unit and conformance test suites.

## Behavior

- Adapter CLI Invocation & Process Spawning (`src/backends/adapters/agy.ts`):
  - Argument Construction:
    - IF `spawn(req)` is called THEN resolve binary executable (`options.bin ?? "agy"`).
    - Append prompt flag `-p` with `req.prompt` AND output formatting `--output-format stream-json`.
    - Append `--model <req.model>`.
    - IF `req.effort` is provided:
      - IF `req.effort` is `"low"`, `"medium"`, or `"high"` THEN append `--effort <req.effort>`.
      - ELSE IF `req.effort` is `"xhigh"` or `"max"`:
        - IF `req.model` is known to reject higher effort tiers (e.g. `gemini-3.8-flash-low`) THEN reject or clamp to `"high"` to prevent CLI conflict crash; ELSE append `--effort <req.effort>`.
    - Append `--mode accept-edits`.
    - IF `capabilities.sandbox_flag` is enabled (or settings enable sandbox) THEN append `--sandbox`.
    - Append `--print-timeout 0s`.
    - IF `req.session?.resume` is present THEN append `--conversation <req.session.resume>`.
  - Process Execution & Supervision:
    - IF `spawn(req)` executes THEN spawn supervised child process via `spawnSupervisedProcess` with `cwd: req.cwd`, scrubbed environment allowlist, and timeout `req.budget.timeout_ms`.
    - IF `rawSink` is configured THEN pipe stdout chunks to `raw/<session_id>.ndjson`.
    - IF process exits or is terminated THEN record exit code, duration, and tail buffers.

- Normalization & Stream Processing (`src/backends/normalize/agy.ts`):
  - Session Initialization:
    - IF raw event has `event === "init"` THEN record `conversation_id`; emit `session.started` with `session_id: conversation_id`.
  - Assistant Text & Turn Updates:
    - IF raw event has `event === "step_update"`:
      - IF `step_update.step_type === "agent_response"`:
        - IF `step_update.text_delta` is non-empty THEN emit `assistant.text` with `text: step_update.text_delta`.
        - IF `step_update.state === "DONE"` AND `step_update.usage` is present THEN compute cost via `calculateCostUsd` with `options.pricing`; emit `usage` event with `UsageRecord` having `cost_source: "computed"` and `cumulative: false`.
      - ELSE IF `step_update.step_type === "tool"`:
        - IF `step_update.state === "ACTIVE"` THEN emit `tool.call` with `id: String(step_update.step_index)`, `name: step_update.tool_name ?? step_update.tool_info.name`, `input_summary: JSON.stringify(step_update.tool_info.parameters)`.
        - ELSE IF `step_update.state === "DONE"` THEN emit `tool.result` with `id: String(step_update.step_index)`, `ok: true`, `output_summary: ""`.
      - ELSE IF `step_update.subagent_info` is present THEN emit `subagent` event with raw subagent payload.
  - Result & Finalization:
    - IF raw event has `event === "result"`:
      - Record final response text from `raw.result.response ?? ""`.
      - IF `raw.result.usage` is present THEN compute total cost with `cost_source: "computed"`; record final usage.
      - IF `raw.result.denied_actions` is non-empty THEN:
        - FOR EACH denial in `denied_actions`: record denial `{ tool: denial.display_name ?? denial.action, reason: denial.action }`; emit `permission.denied`.
      - IF `raw.result.status === "ERROR"` THEN:
        - IF error message indicates rate limit THEN emit `error` with `kind: "rate_limit"`.
        - ELSE IF error message indicates auth failure THEN emit `error` with `kind: "auth"`.
        - ELSE emit `error` with `kind: "crash"` and error message.
      - Emit `session.result` with `ok: (status === "SUCCESS" && denials.length === 0)`, final text, computed usage, and exit code.

- Soft-Deny Detection:
  - Exit 0 Denial Scan:
    - IF child process exits with exit code 0:
      - IF `denied_actions` in result event contains one or more entries THEN classify session as soft-denied; record denials and set `SessionResult.ok = false`.
      - ELSE IF stderr output matches `jetski: no output produced — a tool required the "([^"]+)" permission that headless mode cannot prompt for, so it was auto-denied`:
        - Extract tool permission name from capture group.
        - Emit `permission.denied` event with tool name and auto-denial explanation.
        - Record in `SessionResult.denials` and set `SessionResult.ok = false`.
      - ELSE IF `raw.result.status === "SUCCESS"` THEN set `SessionResult.ok = true`.
    - ELSE IF child process exits with non-zero code THEN set `SessionResult.ok = false`.

- Cost Computation (`src/backends/pricing.ts`):
  - Token Calculation:
    - IF `AgyUsage` is processed THEN extract `input_tokens`, `output_tokens`, `thinking_tokens`, `cache_read_tokens`.
    - Map `thinking_tokens` to `reasoning_tokens` or add to output calculation.
    - Compute total dollar cost via `calculateCostUsd(pricing, model, tokens)`.
    - Return `UsageRecord` with `cost_usd`, `cost_source: "computed"`, `backend: "agy"`, and timestamp.
    - IF model is missing from `pricing.models` THEN throw pricing lookup error.

- Environment Validation (`validateEnvironment()`):
  - Version Check:
    - IF `agy --version` exits 0 THEN parse version output.
    - IF parsed version strictly equals `capabilities.version_pin` (`"1.4.0"`) THEN return `EnvReport` with `ok: true, pin_matches: true, problems: []`.
    - ELSE return `EnvReport` with `ok: true, pin_matches: false, problems: ["agy version mismatch: expected 1.4.0, found <ver>"]`.
    - ELSE IF binary execution fails THEN return `EnvReport` with `ok: false, pin_matches: false, problems: ["agy binary not found or failed to execute"]`.

- Fake Dialect Implementation (`test/fixtures/fake-harness/dialects/agy.mjs`):
  - Dialect Generation:
    - IF scenario is `"success"` THEN emit `init`, `step_update` (user_input DONE, agent_response ACTIVE, agent_response DONE), and `result` with status `"SUCCESS"`.
    - IF scenario is `"soft_deny"` THEN emit `init`, tool ACTIVE `run_command`, tool DONE, write `jetski: no output produced...` to stderr, and emit `result` with `denied_actions: [{ action: "command", display_name: "RunCommand" }]`.
    - IF scenario is `"resume"` THEN verify `--conversation` argument; emit `init` echoing conversation ID, sequential step indices, and cumulative token counters.
    - IF scenario is `"hang"` THEN hold process open without emitting final result.
    - IF scenario is `"crash"` THEN exit immediately with non-zero code.
    - IF scenario is `"rate_limit"` THEN emit error event and `result` with status `"ERROR"`.
    - IF scenario is `"budget_overshoot"` THEN emit usage with tokens exceeding budget.
    - IF scenario is `"edit_files"` THEN modify target files in workspace and emit success result.

## Invariants

- Architectural boundaries: `src/backends/normalize/agy.ts` and `src/backends/adapters/agy.ts` import strictly from `src/contracts/**`, `src/util/**`, other `src/backends/**` modules (such as `process.ts` and `pricing.ts`), and Node standard libraries. They never import `engine`, `git`, `spec`, `verify`, `roles`, `config`, `ledger`, `cli`, or `tui`.
- Never treat exit code alone as success (Plan §11.1 requirement 2 / invariant I11): agy exits 0 on auto-denied tools; success requires `exitCode === 0` AND `status === "SUCCESS"` AND `denials.length === 0` AND no unhandled fatal error.
- Cost source invariant: all `UsageRecord` objects produced by `AgyNormalizer` and `AgyAdapter` MUST have `cost_source: "computed"` (Plan §10, §11.1 requirement 5) since agy reports token counts only without dollar costs.
- Capability declarations: adapter declares `name: "agy"`, `version_pin: "1.4.0"`, `effort: true`, `structured_output: false`, `budget_flag: false`, `cost_reported: false`, `resume: true`, `permission_denial_signal: "stderr"`, `sandbox_flag: true`, `native_subagents_headless: false`.
- Deterministic test execution: tests run against local fake harness dialect (`test/fixtures/fake-harness/dialects/agy.mjs`); real model calls or live network access are strictly gated behind `AGY_LIVE` environment variable and never run in standard CI.
- Process group isolation: supervisor spawns with `detached: true` on POSIX and terminates entire process groups via negative PID (`-pgid`) on kill or timeout.
- Staged termination escalation: `kill(reason)` issues `SIGTERM` first, waits up to `gracePeriodMs` (default 5000 ms), and escalates to `SIGKILL` only if the process group remains active.
- Raw stream persistence: all raw ndjson stdout chunks are written to `raw/<session_id>.ndjson`.
- Conformance compliance: `AgyAdapter` must pass the shared adapter conformance suite (`test/conformance/**`).

## Edge cases

- Soft-deny with exit 0: model tool invocation is denied by policy, tool step finishes without output, and agy exits 0; adapter identifies denial via `denied_actions` or stderr `jetski:` note, sets `SessionResult.ok: false`, and populates `SessionResult.denials`.
- Empty response on soft-denial: when a tool is denied, agy response string may be empty (`""`); normalizer preserves empty text without throwing or hanging.
- Denial signal split between stderr and stream: normalizer aggregates denials detected from stderr lines and NDJSON `denied_actions` payload, deduplicating identical tool records.
- Effort flag conflict on flash models: spike S3 confirmed `--effort max` with `gemini-3.8-flash-low` causes exit 1 conflict error; adapter restricts effort values to `low`, `medium`, or `high` matching model slug tier.
- Missing model in PricingTable: if agy runs with an unlisted model, cost calculation raises a clear configuration error instead of returning NaN or zero.
- Cumulative token accounting across resumed turns: spike S3 proved agy reports cumulative input tokens on resumed sessions; normalizer tracks previous turn baseline to calculate incremental tokens for step `usage` events while reporting cumulative total in `SessionResult`.
- Process killed before result event: if child process is terminated by timeout, budget, or cancel signal, adapter constructs `SessionResult` with `ok: false`, `killed_for: reason`, partial usage, and non-zero exit code.
- Malformed or truncated NDJSON line: NDJSON reader drops torn line fragments and invokes parse error handler without crashing event iteration.
- Non-zero exit code with partial stream: if agy exits with status `ERROR` and exit code 1, normalizer surfaces typed `error` event and completes with `SessionResult.ok: false`.

## Open questions

- How should multi-turn token accumulation in resumed agy sessions be reported in step `usage` events: should `record.input_tokens` reflect the incremental turn tokens or the cumulative session tokens when `cumulative` is false? The specification assumes incremental tokens for turn events and cumulative tokens in `SessionResult.usage`.
- When agy runs under `--sandbox`, does it require Substrate to write custom permission grant rules to `~/.gemini/antigravity-cli/settings.json` in advance to prevent soft-denying terminal commands? The specification assumes headless workers operate with explicit allow rules or fall back to soft-deny detection.
