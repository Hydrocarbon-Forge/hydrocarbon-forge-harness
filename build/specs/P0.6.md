## Objective

Document and synthesize the interactive user experience (UX) conventions across Claude Code, OpenCode v2, and Antigravity, resolving Unknown U9 and producing `docs/spikes/S5-ux.md`:
1. Slash commands: catalog exact built-in slash commands, argument parsing conventions, aliases, and expansion semantics of all three harnesses.
2. Keybindings: document terminal keyboard shortcuts across prompts, execution states, interrupt flows, and modal dialogs for each harness.
3. Status line: document status line segments (model/tier, run state, progress, cost/budget cap) and rendering adaptations for narrow terminals.
4. Synthesis for Substrate TUI (P5.3): define the canonical 18 slash commands (§4.7: `/help`, `/mode`, `/plan`, `/run`, `/status`, `/tasks`, `/cost`, `/models`, `/agents`, `/permissions`, `/config`, `/resume`, `/sessions`, `/undo`, `/doctor`, `/init`, `/clear`, `/exit`, `/hooks`), the canonical keymap (`Enter`, `Esc`, `Shift+Tab`, `Ctrl+C` x 2, `Ctrl+T`, `Ctrl+O`, `@`, `!`), and responsive status line layout.

## Behavior

- IF parsing user input in the interactive TUI prompt:
  - IF input begins with `/`:
    - IF command matches a built-in slash command (`/help`, `/mode`, `/plan`, `/run`, `/status`, `/tasks`, `/cost`, `/models`, `/agents`, `/permissions`, `/config`, `/resume`, `/sessions`, `/undo`, `/doctor`, `/init`, `/clear`, `/exit`, `/hooks`) THEN route to the matching handler in the slash command registry.
    - ELSE IF command matches a custom command in `.substrate/commands/*.md` THEN load template, substitute arguments, and feed expanded prompt to runner.
    - ELSE THEN display unknown command error and suggest `/help`.
  - ELSE IF input begins with `!` THEN execute trailing command in local shell passthrough.
  - ELSE IF input contains `@` token THEN trigger file-mention autocompletion against workspace paths.
  - ELSE THEN submit prompt to governor or deterministic run loop upon `Enter`.
- IF handling keyboard events in TUI:
  - IF `Ctrl+C` is pressed:
    - IF pressed again within 500ms THEN emit exit signal and terminate process cleanly with exit code 130.
    - ELSE THEN display exit confirmation banner ("Press Ctrl+C again to exit") and arm 500ms reset timer.
  - ELSE IF `Esc` is pressed:
    - IF run is actively executing THEN signal engine to pause run with `PAUSED(user_cancel)` at next safe boundary.
    - ELSE IF modal dialog or task board overlay is open THEN dismiss overlay and return focus to prompt input.
    - ELSE THEN clear current prompt input buffer.
  - ELSE IF `Shift+Tab` is pressed:
    - IF cursor is in prompt input THEN cycle `--permission-mode` through (`default` -> `plan` -> `acceptEdits` -> `dontAsk` -> `bypassPermissions` -> `default`).
    - ELSE THEN ignore.
  - ELSE IF `Ctrl+T` is pressed THEN toggle task board split pane between hidden and visible states.
  - ELSE IF `Ctrl+O` is pressed THEN toggle event feed verbosity between compact summary and expanded trace.
- IF rendering terminal status line:
  - IF terminal width >= 100 columns THEN render full layout: `[model/tier] [run state] [tasks done/total] [cost / cap]`.
  - ELSE IF terminal width >= 60 columns THEN drop lowest priority segment (`model/tier`), rendering: `[run state] [tasks done/total] [cost / cap]`.
  - ELSE THEN render minimal collapsed status: `[state] [done/total]`.
- IF generating `docs/spikes/S5-ux.md`:
  - IF documenting Claude Code THEN record observed slash commands (`/config`, `/model`, `/effort`, `/cost`, `/doctor`, `/permissions`), keybindings (`Enter`, `Esc`, `Shift+Tab`, `Ctrl+C` x 2), and statusline setup.
  - IF documenting OpenCode THEN record v2 command syntax, keybindings, and terminal footer state.
  - IF documenting Antigravity THEN record slash commands (`/agents`, `/permissions`, `/config`, `/model`, `/effort`, `/resume`), shortcuts, and status reporting.
  - IF synthesizing for Substrate P5.3 THEN synthesize all three into canonical TUI registry, keymap, and status line answering U9.

## Edge cases

- Terminal lacking ANSI color or UTF-8 box-drawing support: fallback to ASCII characters for status line and borders.
- Terminal resize (`SIGWINCH`) during active run: dynamic re-computation of segment priorities without buffer corruption.
- Built-in vs custom command collision: built-in command takes strict precedence; log warning about shadowed custom command.
- Rapid successive interrupts (`Esc` spam): engine debounces signals and maintains consistent `PAUSED` state.
- Empty or whitespace-only input at prompt: `Enter` press is ignored without triggering empty runs.
- Extremely narrow viewport (< 40 columns): hide status line or collapse to single-character state indicator.
