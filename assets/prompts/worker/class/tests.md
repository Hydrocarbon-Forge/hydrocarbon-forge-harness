Class: tests. Write test files only, against the contract stubs. Test the targets the spec lists in Behavior and Edge cases, one focused test per target, and nothing the spec marks Out of scope. Never modify application source. Target the interface the spec describes. Tests must be deterministic and assert real behaviour, not just that code runs. The implementation may not exist yet, so do not require the tests to fail or pass now. Do not mock the code under test. Your verify commands prove the tests compile.
