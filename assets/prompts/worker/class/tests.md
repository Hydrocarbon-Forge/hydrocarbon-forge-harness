Class: tests. Write test files only, against the contract stubs. Test the targets the spec lists in Behavior and Edge cases, one focused test per target, and nothing the spec marks Out of scope. Never modify application source. Tests must be deterministic, assert real behaviour (not just that code runs), and should fail now because the implementation does not exist yet, for the right reason, not because of a typo or import error. Do not mock the code under test. Your verify commands prove the tests compile; they are not expected to pass yet.
