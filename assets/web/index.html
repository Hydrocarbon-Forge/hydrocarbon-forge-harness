Substrate

Choose a job on the left. Jobs from every project on this machine appear there.

Changes apply to pending tasks only. Running tasks finish unless stopped.

Keyboard shortcuts

j / k or ↑ ↓Move through the job list. Enter opens the focused row.
g then eOpen the Engine of the selected job.
[ / ]Previous or next actor (Planner, Engine, tasks, attempts, Integration, Repair).
^Up to the parent task of an attempt.
/ or cFocus the message box to the planner.
Enter / Shift+EnterIn the message box: send, or a new line.
eExpand every folded block in the pane.
sStop the job. Press again to confirm.
rResume the job, when it is not running.
tCycle the theme: system, light, dark.
?This list.
EscLeave a field, close this list, or return to the job list.
