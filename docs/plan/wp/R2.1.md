## Objective
Give Substrate real default prices and a policy that never loses a usage record or reports an unknown cost as $0. Today the default pricing is a placeholder with no models (C-H20, S-M1), and an unlisted model makes the cost calculation throw. After this WP a usage record for an unpriced model is kept with `cost_source: "unknown"` and `cost_usd: 0`, and the stream continues. You change no file under `src/engine/`, `src/roles/` or `src/cli/`.

## Interface
`src/backends/default-pricing.ts` exports `DEFAULT_PRICING: PricingTable`. It holds exactly the values in `docs/spikes/S4-pricing.json` (copy them by hand; the spike file is not read at runtime). `asOf` is `"2026-10-16"`, `sources` are the two URLs in that file, and `models` has the four entries `claude-haiku-5-5`, `claude-opus-5-5`, `claude-sonnet-5-5` and `gemini-3.8-flash`, with their rates. `gemini-3.8-flash` has no `cache_write_per_mtok`.

`src/backends/pricing.ts`:
- `pricingTableFor(settings: Settings): PricingTable` returns `DEFAULT_PRICING` with `settings.pricing.models` overlaid by model id (an entry in settings replaces the built-in entry for that id; other built-in entries are kept).
- `calculateCostUsd(pricing, model, tokens): { cost_usd: number; cost_source: "computed" | "unknown" }`. An unlisted model returns `{cost_usd: 0, cost_source: "unknown"}` and does not throw. A listed model returns the computed cost, and cache tokens count only when the model has a rate for them; otherwise they are excluded from the cost.
- `computeUsageRecord(pricing, raw)` uses `calculateCostUsd` and sets `cost_usd` and `cost_source` from it. It does not throw for an unlisted model.

`src/contracts/index.ts`: `UsageRecord.cost_source` is `z.enum(["reported", "computed", "unknown"])`. `Settings.pricing` becomes `z.object({ asOf: z.string().optional(), sources: z.array(z.string()).optional(), models: z.record(z.string(), <rates>).optional() }).strict()`, where `<rates>` is the existing rate object. `PricingTable` is unchanged.

`src/config/index.ts`: `DEFAULT_SETTINGS.pricing` becomes `{ models: {} }`; the placeholder `example.com` source is removed.

## Behavior
1. Unlisted model: `calculateCostUsd` returns `{0, "unknown"}`. `computeUsageRecord` keeps the record with `cost_usd: 0`, `cost_source: "unknown"`. Invalid token counts (negative, NaN, infinite) still throw `Invalid input_tokens: <n>` (and the same for output and cache fields).
2. Cache tokens: `cache_read_tokens` is charged only when the model has `cache_read_per_mtok`; `cache_write_tokens` only when it has `cache_write_per_mtok`. Otherwise those tokens add nothing to the cost.
3. Claude normalizer (`normalize/claude.ts`): when the result event has `total_cost_usd`, the record has `cost_source: "reported"` and that cost. When it is absent, the cost is computed with `pricingTable` passed in `ClaudeNormalizerOptions.pricing` (new optional field), with the same unknown policy.
4. OpenCode normalizer: keep the current rule (compute only when the harness reports 0 for a priced model), but pass the table through `OpenCodeNormalizeOptions.pricingTable`, and replace the empty `catch` (the "Unlisted model" comment) with the non-throwing calculation, so an unlisted model yields `cost_source: "unknown"` and keeps the reported 0.
5. OpenCode adapter (`adapters/opencode.ts`): `OpenCodeAdapterOptions` gains `pricing?: PricingTable`; the adapter passes it to the normalizer as `pricingTable`. When no table is given, use `DEFAULT_PRICING`.
6. agy normalizer (`normalize/agy.ts`): `toUsageRecord` uses the non-throwing calculation. If it still throws (invalid tokens), the usage step pushes an `error` event with `kind: "protocol"` and a message naming the step, logs it with `log.warn` (`src/util/log.ts`), and the stream continues. No silent catch.
7. `pricingTableFor` is the only way the rest of the code obtains the table. No caller reads `settings.pricing.models` directly.

## Invariants
- A usage record is never dropped because of a price. Every record in the output of a normalizer exists once per usage step.
- `cost_usd` is never negative. An unknown record has `cost_usd: 0` and `cost_source: "unknown"`, and reports must show it as unknown (R2.8).
- `DEFAULT_PRICING` values equal `docs/spikes/S4-pricing.json` exactly.

## Edge cases
- Settings override for a built-in model id: the settings rates are used, the built-in asOf and sources stay.
- A model id that differs only by the `#variant` suffix: the normalizer uses the model without the variant (R2.4 rule); an unlisted base id is unknown.
- `cache_read_tokens` present for `gemini-3.8-flash` (cache read rate present, cache write rate absent) and `cache_write_tokens` present: the write tokens add nothing.
- Zero tokens for a listed model: cost 0 with `cost_source: "computed"`.

## Guardrails
- Not done if the placeholder pricing still ships in `DEFAULT_SETTINGS` (grep for `example.com` in `src/config/index.ts` must print nothing).
- No stubs, TODO, FIXME, placeholder bodies, or a cost of 0 presented as `computed` for an unpriced model.
- Do not change the `backends.*` adapter spawn logic beyond the pricing option in `adapters/opencode.ts`. The agy adapter's model fallback (`adapters/agy.ts` around the pricing lookup) belongs to R2.5.
- Do not write an IP address or port in any file.

## Out of scope
The price for any model not in S4, the `usage` report (R2.8), `substrate models` price columns (R2.7), and the agy adapter (R2.5).
