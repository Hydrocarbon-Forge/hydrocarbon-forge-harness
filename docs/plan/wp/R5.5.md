## Objective
Retire the work-package plan once it is complete. Move the R-series plan files to a dated archive, keep the binding decisions where they are, and make `START-HERE.md` describe the post-remediation state. Nothing is deleted.

## Interface
- Archive directory: `docs/archive/<YYYY-MM-DD>-r-series/`, where the date is the date of this commit (`date +%F`).
- Moved, with `git mv`: `docs/plan/wp/` (directory, all `R*.md` files) to `docs/archive/<date>-r-series/wp/`; `docs/plan/IMPLEMENTATION-PLAN.md` to `docs/archive/<date>-r-series/IMPLEMENTATION-PLAN.md`; `docs/plan/PROGRESS.md` to `docs/archive/<date>-r-series/PROGRESS.md`.
- Kept in place: `docs/plan/DECISIONS.md`, `docs/plan/reference/AUDIT-FINDINGS.md`, `docs/plan/BLOCKED.md` (if it exists).

## Behavior
1. Precondition: every row of `docs/plan/PROGRESS.md` (R0.1 to R5.4) is DONE. Otherwise stop and report the first row that is not.
2. Mark R5.5 DONE in `docs/plan/PROGRESS.md`, commit that change alone, then perform the moves in a second commit.
3. After the moves, `docs/plan/` contains `DECISIONS.md` and `reference/AUDIT-FINDINGS.md`, and nothing else plan-related.
4. `START-HERE.md` is rewritten to describe the current state: the binding decisions, the CLI as it now exists, how to run `npm run check`, `npm test` and `npm run docs:check`, and a pointer to the archive for the R-series history. It contains no governor default, no TUI claim, and no stub-status language.
5. Any link or path in `README.md`, `START-HERE.md` or `docs/` that points at a moved file is updated to the archive path. `docs/plan/DECISIONS.md` is not changed.
6. Remove the entries in `scripts/debt-allowlist.json` for `R5.5` (none are expected).

## Invariants
- No file is deleted. Every moved file keeps its content byte for byte (`git mv`, not copy and edit).
- `docs/plan/DECISIONS.md` is byte-identical before and after.

## Edge cases
- `docs/plan/BLOCKED.md` exists: moved with the archive, and recorded in Notes.
- A link to `docs/plan/wp/` in `SUBSTRATE-PLAN.md`: updated to the archive path, not removed.

## Guardrails
- No security hardening beyond the plan (DECISIONS A6): no new sandbox, environment scrubbing or permission-file checks.
- Never write a raw IP address or port in code, specs, docs or fixtures.
- Not done if the move leaves a broken path. `npm run docs:check` must pass.
- Do not rewrite the R-series content. Only the status and the location change.
- No placeholder text in `START-HERE.md`.

## Out of scope
Governor removal (R5.6). New documentation (R5.2 already done). Any `src/` change.

## Done when
1. `npm run docs:check` exits 0.
2. `npm run typecheck` exits 0 and `npm run check` exits 0.
3. `ls docs/plan` shows only `DECISIONS.md` and `reference`, and `ls docs/archive/*-r-series` shows `wp`, `IMPLEMENTATION-PLAN.md` and `PROGRESS.md`.
4. `git diff --stat -M HEAD~1 -- docs/plan/DECISIONS.md` is empty.
5. Mark R5.5 DONE in the archived `PROGRESS.md` (the moves already happened), and commit as `R5.5: Archive the R-series`.

## Notes for the implementer
- The check script `scripts/check-plan.mjs` prints `no docs/plan/PROGRESS.md work packages found` after the move. That is expected and exits 0.
- VERIFY FIRST: `grep -rn "docs/plan/wp\|PROGRESS.md\|IMPLEMENTATION-PLAN" --include=*.md --include=*.mjs . | grep -v node_modules` lists every reference before moving.
