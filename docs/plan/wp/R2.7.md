## Objective
Let a person or Hermes see every model available on this machine, by provider and overall, with the price per million tokens and which configured route uses each model. `substrate models` must work when a provider is not installed (it lists it as not installed, never as an error). After this WP the command and its JSON output are proven through the bundle with fake harnesses. You change no file under `src/engine/`, `src/roles/` or `src/backends/`.

## Interface
`src/cli/model-catalog.ts` exports:
- `ModelCatalog` (zod, `.strict()`): `{ v: 1, generated_at: string, cache: "fresh" | "cached", providers: ProviderEntry[], all_models: ModelEntry[] }`.
- `ProviderEntry`: `{ provider: "claude" | "opencode" | "agy", installed: boolean, version?: string, version_pin?: string, pin_matches: boolean, problems: string[], models: ModelEntry[] }`.
- `ModelEntry`: `{ id: string, provider: string, display?: string, efforts: string[], source: "cli" | "static" | "settings", price_per_mtok: { input: number; output: number } | null, slots: string[] }`. `price_per_mtok` is `null` when the model is unpriced. `slots` lists the places that use the model: `roles.planner`, `roles.worker`, `routing.<class>` (until R2.9 adds profiles).
- `buildCatalog(opts: { settings: Settings; adapters: Record<string, HarnessAdapter>; refresh: boolean; cacheFile: string; now?: Date }): Promise<ModelCatalog>`.

`src/config/index.ts` exports `modelCacheFile(projectRoot: string): string` returning `<projectRoot>/.substrate/state/models.json`.

`substrate models [--provider claude|opencode|agy] [--refresh] [--output-format json|text]` (in `src/cli/commands/models.ts`).

## Behavior
1. For each provider in `claude`, `opencode`, `agy` (or only `--provider`): call `validateEnvironment()` and `listModels()` on its adapter from `createAdapters(settings)` (R2.2). If `validateEnvironment` or `listModels` throws, set `installed: false` (for a missing binary) and `models: []`; record the message in `problems`. Never exit non-zero for an uninstalled provider.
2. `installed` is `validateEnvironment().ok`, `version` is the reported version, `version_pin` is the adapter's `capabilities.version_pin`, `pin_matches` is the report's `pin_matches`.
3. `price_per_mtok` comes from `pricingTableFor(settings)` (R2.1) by model id. A model with no price has `null`.
4. `slots`: `roles.planner.model` gives `roles.planner`; `roles.worker.model` gives `roles.worker`; each `routing.<class>` whose `model` matches gives `routing.<class>`. A model used by no entry has `[]`.
5. `all_models` is the concatenation of every provider's models, sorted by provider then id.
6. Cache: the catalog is stored at `modelCacheFile` with `{v: 1, generated_at, providers}`. A cache file younger than 24 hours is used when `--refresh` is not given (`cache: "cached"`). `--refresh` ignores the cache and rewrites it (`cache: "fresh"`). A corrupt cache file is ignored and rewritten.
7. Text output: one table per provider with a header `== <provider> (installed|not installed, version <v>, pin <p> matches|does not match) ==`, then one row per model: `id`, `efforts` (comma list or `-`), `price in/out per Mtok` (or `unpriced`), `used by` (slots or `-`). Then `== all models ==` with one row per model prefixed by the provider. Text goes to stdout.
8. JSON output (`--output-format json`): exactly one `ModelCatalog` object on stdout, nothing else on stdout. Errors (an unknown `--provider` value) print `{"error": "..."}` on stdout and exit 2.
9. Exit code is 0 unless the arguments are invalid (exit 2).

## Invariants
- `ModelCatalog` parses with `ModelCatalog.parse` for every output.
- The command never runs a model call; it only runs `--version`-style checks and the listing commands.
- An unpriced model is shown as `unpriced`, never as a price of 0.

## Edge cases
- No provider installed: four lines `not installed`, `all models` empty, exit 0.
- `--provider foo`: `Error: unknown provider foo` on stderr, exit 2.
- Cache older than 24 hours: ignored.
- `--refresh` with `--provider claude`: only claude is refreshed; the other providers' cache entries are kept.

## Guardrails
- Not done if the command works only through a test that calls `buildCatalog` directly. The E2E test (Done when 3) runs `node dist/substrate.mjs models` from the bundle.
- No stubs, TODO, FIXME, placeholder bodies, hard-coded model lists, or invented prices.
- No write outside `.substrate/state/models.json`.
- Do not write an IP address or port in any file.
