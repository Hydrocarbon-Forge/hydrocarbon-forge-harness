## Objective
Prove the whole product through the built CLI in one matrix. Every scenario in SUBSTRATE-PLAN section 14, plus the request, local-model, crash and git-command paths, runs with the fake harness for every dialect. The debt allowlist ends empty.

## Interface
- `test/e2e/matrix.test.ts` is a table-driven suite. Each row is `{id, name, dialects, run(ctx) => Promise<void>}` and uses `runSubstrate` (from `test/e2e/helpers/run-substrate.ts`) and `test/e2e/helpers/repo.ts`.
- Dialects: `claude`, `opencode`, `agy`. Rows that test engine behaviour run with each dialect (the `dialects` field).
- `scripts/debt-allowlist.json`: every array (`purity`, `wired`, `events`, `settings`, `dead`) is `[]`. The `events_observe_only` array is kept unchanged.

## Behavior
1. Rows, one per scenario of SUBSTRATE-PLAN 14 (1 to 16), with the scenario's expected exit and events:
   - 1 all-pass batch: exit 0, `batch.merged`.
   - 2 fail, heal, pass: exit 0, `task.healing` with real failing output.
   - 3 double fail, packet, L1 replan, pass: exit 0, a packet file.
   - 4 scope violation reverted: exit 0, `scope.checked` with violations, file reverted.
   - 5 protected file modified: `task.failed` `protected_modified`.
   - 6 permission denial: exit 3, `run.paused` `permission_denied`.
   - 7 budget kill: exit 4 (run budget) or a task `budget_exceeded`.
   - 8 timeout kills the process group: `task.failed` `timeout`, no live child pids.
   - 9 merge conflict: `merge.conflict` then L1.
   - 10 integration failure: `bisect.culprit`.
   - 11 crash and resume at every event boundary: for each index i of a finished reference run's `events.jsonl`, truncate to i events, `resume`, and assert exit 0 and the same final task states.
   - 12 rate-limit backoff: `rate_limit.backoff` events.
   - 13 planner format retry: success after one retry; and failure after exhausted retries (exit 1).
   - 14 L2 amendment invalidates dependents only: `tasks.invalidated` excludes MERGED tasks.
   - 15 governor-free request run: `run --request` (R4.1) exits 0 with no governor setting present.
   - 16 solo mode: exit 0 (R3.8).
2. Extra rows: local-model route (R4.3); SIGKILL then resume (R3.2); `merge`, `undo`, `discard` on a temp repo (R3.7); `--output-format json` and `stream-json` outputs parse with `JSON.parse` line by line; every dialect for the rows that use an executable.
3. A final row runs `git grep -n "val_\${" src` in the repository and expects no output, and `git grep -n "console.log" src/engine` and expects no output.

## Invariants
- The matrix uses only fake executables. No row calls a real model.
- Each row's assertions come from the event log or the process exit, not from console text alone.
- Every row removes its temp directories.

## Edge cases
- Row 11 with a boundary that lands inside a task: the resume must still finish (R3.2 rule 8).
- A dialect that cannot express a scenario (for example stream-json for a permission denial): the row lists only the dialects that can.

## Guardrails
- No security hardening beyond the plan (DECISIONS A6): no new sandbox, environment scrubbing or permission-file checks.
- Never write a raw IP address or port in code, specs, docs or fixtures.
- Not done if the matrix only exists. Each row must run and pass.
- Do not skip a row to make the suite green. A row that fails is a finding: fix the code in the WP that owns it, or stop and record it in `docs/plan/BLOCKED.md`.
- No `it.fails` markers. No test-only branches in `src/`.
- Do not edit `src/` in this WP.

## Out of scope
Live harness runs (R5.3). Governor removal (R5.6). Documentation (R5.2).

## Done when
1. `npm run typecheck` exits 0.
2. `npx vitest run test/e2e/matrix.test.ts` passes with all rows, and its output lists the row count (at least 16 scenario rows plus the extra rows).
3. `npm test` and `npm run check` pass with the allowlist containing empty arrays.
4. Delete the entries in `scripts/debt-allowlist.json` whose `until` is `R5.4`, which leaves all arrays empty.
5. Mark R5.4 DONE in `docs/plan/PROGRESS.md` with the matrix row count and the `npm run check` output in Notes, and commit as `R5.4: Final wiring audit and E2E matrix`.
