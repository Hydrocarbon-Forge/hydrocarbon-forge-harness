## Objective
Let each adapter say which models its harness offers, so that `substrate models` (R2.7) and `init` (R2.10) list real choices and never invent ids. Claude has no list command, so its list is static aliases plus the ids in settings and the price table. OpenCode and agy are parsed from their own `models` commands. After this WP every adapter has `listModels()`, and parser tests run on fixtures. You change no file under `src/engine/`, `src/cli/` or `src/config/`.

## Interface
`src/contracts/index.ts` gains:
```ts
export const ModelInfo = z.object({
  id: z.string(),
  display: z.string().optional(),
  efforts: z.array(z.string()),
  source: z.enum(["cli", "static", "settings"]),
}).strict();
export type ModelInfo = z.infer<typeof ModelInfo>;
```
`HarnessAdapter` (type and zod object) gains `listModels(): Promise<ModelInfo[]>`.

Deviation to record in Notes: `efforts` is `string[]` (the provider's native variant names, for example OpenCode `none`, `minimal`), not the `Effort` enum, because OpenCode's variants are not `Effort` values. Claude's efforts are the `Effort` enum values.

`ClaudeAdapterOptions` gains `knownModels?: string[]` (ids from settings and the price table, passed in by the registry). `OpenCodeAdapterOptions` gains `modelsTimeoutMs?: number` (default 30000). `AgyAdapterOptions` is unchanged.

Parsers exported (for tests): `parseOpenCodeModels(text: string): ModelInfo[]` and `parseAgyModels(text: string): ModelInfo[]`, both in their adapter files.

## Behavior
1. Claude `listModels()`: returns the static aliases `haiku`, `sonnet`, `opus`, `fable` with `source: "static"` and efforts `["low","medium","high","xhigh","max"]`, then one entry per id in `knownModels` (deduplicated, in order) with `source: "settings"` and efforts from the same list. No command is run.
2. OpenCode `listModels()`: runs `opencode models --standalone` with `execFile` (cwd is `process.cwd()`, timeout `modelsTimeoutMs`). On a non-zero exit or a timeout, it throws `opencode models failed: <message>`. `parseOpenCodeModels` takes the stdout: each non-blank line that does not start with `#` gives the first whitespace-separated token as the id, `display` is the rest of the line trimmed (omitted when empty), `source: "cli"`. Efforts come from the id's family: contains `openai/` or `gpt` gives `["none","minimal","low","medium","high","xhigh"]`; contains `anthropic/` or `claude` gives `["high","max"]`; contains `google/` or `gemini` gives `["low","high"]`; otherwise `[]`.
3. agy `listModels()`: runs `agy models` (same error rule with the message `agy models failed`). `parseAgyModels` takes the stdout: lines that match `^[A-Za-z0-9][A-Za-z0-9._-]*\t` give `id` (before the tab) and `display` (after the tab). The line `Fetching available models...` and any other line are skipped. Efforts: a slug ending in `-low`, `-medium` or `-high` gives `[low|medium|high]` (the tier); other slugs give `[]`. `source: "cli"`.
4. `test/fixtures/backends/agy/models.txt`: capture with `agy models > test/fixtures/backends/agy/models.txt` when `agy` is installed (the header line `Fetching available models...` stays in the file). The parser test must pass on the captured file.
5. `test/fixtures/backends/opencode/models.txt`: `opencode models --standalone` printed no lines in the authoring environment (no configured providers). Write this file with the header line `# UNVERIFIED: format assumed, one model id per line; recapture with opencode models --standalone when providers are configured` followed by the one id that S2 observed, on its own line: `opencode/deepseek-v4.1-flash-free`.
6. Fake harness dialects: `dialects/opencode.mjs` and `dialects/agy.mjs` answer the first argument `models` by writing the contents of their fixture (`test/fixtures/backends/<name>/models.txt`, resolved relative to the dialect file) to stdout and exiting 0.
7. `test/conformance/fake-adapter.ts`: `FakeAdapter.listModels()` returns one entry `{id: "fake-model", efforts: [], source: "static"}`.
8. `registry.ts` passes `knownModels` to the Claude adapter: the ids from `settings.roles` and `settings.routing` (every `model` string) and the keys of the price table.

## Invariants
- No `listModels` implementation returns an id that is not in its source (a command output, a fixture, a static alias, or settings or the price table).
- The parsers never throw on empty input; they return `[]`.
- Claude's `listModels` never runs a process.

## Edge cases
- `opencode models` empty output (as observed): `[]`, not an error.
- agy output with a Windows line ending: `\r` is stripped before parsing.
- Duplicate ids in `knownModels`: one entry.
- A model id with `#variant` in settings: the id is kept as written.

## Guardrails
- Not done if the parsers are tested only with inline strings. The tests read the fixture files (`test/fixtures/backends/agy/models.txt` and `opencode/models.txt`).
- No stubs, TODO, FIXME, placeholder bodies, or a hard-coded model list in an adapter other than the Claude aliases in step 1.
- Do not invent a model id that the harness did not report. The OpenCode fixture id comes from the spike (S2), and the header marks the file UNVERIFIED.
- Do not write an IP address or port in any file.

## Out of scope
The `models` command and its table (R2.7), profiles (R2.9), `init` (R2.10), and any change to how a model is run.
