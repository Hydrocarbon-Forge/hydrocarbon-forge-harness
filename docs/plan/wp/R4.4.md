## Objective
Every finished run leaves a compact, committable record in `.substrate/archive/<version>/<run_id>/`, listed in `INDEX.md`. Users and agents can list archived runs with `history`, archive a run by hand, and delete raw run data that is already archived.

## Interface
- `src/archive/index.ts` exports:
  - `currentVersion(substrateDir: string): string`: the `version:` frontmatter of `.substrate/charter.md` when present, else `v1`.
  - `archiveRun(opts: {repoRoot, runId, runDir, version}): Promise<ArchiveRecord>` where `ArchiveRecord = {run_id, status, goal, ended_at, dir}`.
  - `readIndex(substrateDir, version): ArchiveRecord[]`.
  - `archiveSummary(record, runDir): string` renders `summary.md`.
- `src/engine/actions/finish.ts` exports the `finish` action. It is called by `runEffectsLoop` whenever the state is FINISHED, FAILED or CANCELLED, and it writes the archive once per run (`archiveRun`).
- CLI: `substrate history [--all-versions] [--output-format json]`, `substrate archive <run>`, `substrate gc [--older-than 30d]`. All three are registered in `src/cli/dispatcher.ts`.

## Behavior
1. Archive directory: `.substrate/archive/<version>/<run_id>/` containing `summary.md`, `manifest.yaml`, `tasks/`, `decisions.md` and `usage.json`.
2. `manifest.yaml`: a copy of the run's manifest when it exists. A solo run (no manifest) gets a file with `run_id`, `mode: solo` and `status`.
3. `tasks/`: copies of the run's `tasks/*.md` and the packet JSON files under `packets/`. Empty when there are none.
4. `decisions.md`: a copy of the run's `decisions.md`. When the run has none, the file says `no decisions.md was written by the planner`.
5. `usage.json`: `{run_id, input_tokens, output_tokens, cost_usd, cost_source_unknown_rows, by_role}` summed from `usage.jsonl` rows for this run (R1.4 ledger). Zero totals when there are none.
6. `summary.md` has these sections in order: `## Goal`, `## Outcome` (status and exit code), `## Tasks` (a table of id, state, generation, failure class), `## Usage` (input and output tokens, cost, unknown rows), `## What was learned` (the first 20 lines of `decisions.md`, or `(none)`).
7. `INDEX.md` gets one line per run: `- <run_id> | <status> | <goal, first 80 characters> | <ended_at>`. A run already listed is not added twice.
8. `substrate archive <run>` re-archives the run (overwrites its directory) and keeps one INDEX line. An unknown run exits 2.
9. `history` lists the current version's runs, or every version with `--all-versions`. Text: one line per run. JSON: `{"version","runs":[ArchiveRecord...]}`, or `{"versions":[...]}` with `--all-versions`.
10. `gc [--older-than 30d]` removes `.substrate/runs/<run_id>/` only for runs that have an archive record and whose archive `summary.md` mtime is older than the cut-off. It prints `removed <n> run(s)`. A run without an archive is never removed.

## Invariants
- The archive contains no secrets beyond what the run's own files contain.
- `summary.md` is written from recorded data only, never from a model's free text beyond `decisions.md`.
- `gc` never deletes an unarchived run, a worktree, or a branch.

## Edge cases
- A failed run is archived with status `failed`; a cancelled run with `cancelled`.
- `archive` on a run still in progress: exit 1, `Error: run <id> is not terminal`.
- Missing `.substrate/archive`: created on first write.
- `history` with no archive: `no archived runs`, exit 0.

## Guardrails
- No security hardening beyond the plan (DECISIONS A6): no new sandbox, environment scrubbing or permission-file checks.
- Never write a raw IP address or port in code, specs, docs or fixtures.
- Not done if archiving is reachable only from tests. The E2E must run `run` (finished and failed) through the built CLI and check the archive files.
- No placeholder summary text. Every section is filled from data or states that there is none.
- No test-only branches in `src/`.

## Out of scope
